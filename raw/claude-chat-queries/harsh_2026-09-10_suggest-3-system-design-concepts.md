Assistant planned response content:
1. Load balancing: spreading traffic across multiple servers so the system stays available and responsive under load.
2. Caching: storing frequently used data closer to where it is needed to reduce latency and database pressure.
3. Event-driven architecture: services communicate through events or message queues, making the system more scalable and loosely coupled.
