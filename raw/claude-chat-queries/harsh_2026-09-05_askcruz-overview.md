## How to Use Slack — Complete Beginner Guide

**User Question:** "How can I use slack?"

---

## WHAT IS SLACK?

Team messaging platform. Like WhatsApp for work, but with organized channels and file sharing.

---

## HOW TO GET STARTED

### Step 1: Download
- Desktop: slack.com/downloads
- Mobile: App Store or Google Play (search "Slack")
- Web: app.slack.com (no download needed)

### Step 2: Sign In
- Click email invitation from your team OR
- Enter email → Slack sends code → Enter code → Enter workspace name
- Workspace name: Ask Ron/Priyanshu (probably "eoxs" or "askcruz")

### Step 3: Explore Interface
- LEFT SIDEBAR = your channels (#3gm-testing, #general, etc.) and direct messages
- CENTER = the conversation you're reading
- TOP = search box

---

## HOW TO USE SLACK

### Send a Message in a Channel
1. Click channel on left (e.g., #3gm-testing)
2. Type message in box at bottom
3. Press Enter
4. Everyone in that channel sees it

Example:
```
"OAuth testing complete, ready for integration ✅"
```

### Send a Direct Message (1-on-1)
1. Click person's name in Direct Messages
2. Type message
3. Press Enter
4. Only they see it

### Get Someone's Attention
Type `@Name` before your message
```
"@Ron Can you review the test results?"
```
Ron gets a special notification

### Share a File
- Drag & drop file into Slack OR
- Click 📎 icon → select file → send

### Reply Without Cluttering
1. Hover over a message
2. Click "Reply in thread"
3. Your reply goes in a separate thread (clean)

### Search Old Messages
- Click search box (top right)
- Type what you're looking for
- Example: "3GM OAuth" or "test results"

### Update Your Profile
1. Click your picture (top right)
2. Edit: name, photo, title, status
3. So team knows who you are

### Mute Notifications
1. Right-click channel
2. Click "Mute channel"
3. You see messages, no ping notifications
